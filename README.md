# Tic-Tac-Toe Game in C++

## About the Project
This is a simple two-player Tic-Tac-Toe game developed using C++.

Player 1 uses **X** and Player 2 uses **O**. Players take turns selecting positions on a 3x3 game board. The first player to complete a row, column, or diagonal wins.

## Features
- Two-player gameplay
- 3x3 game board
- Automatic winner detection
- Draw detection
- Invalid position checking
- Prevents occupied positions

## Technologies Used
- C++
- Arrays
- Functions
- Loops
- Conditional Statements

## How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Compile the program:

```bash
g++ tic_tac_toe.cpp -o tic_tac_toe
```

4. Run the program:

```bash
./tic_tac_toe
```

On Windows, run:

```bash
tic_tac_toe.exe
```

## How to Play
1. Player X starts the game.
2. Enter a position from 1 to 9.
3. Player O takes the next turn.
4. Complete a row, column, or diagonal to win.
5. If all positions are filled without a winner, the game is a draw.

## Sample Board

```text
 1 | 2 | 3
---|---|---
 4 | 5 | 6
---|---|---
 7 | 8 | 9
```
